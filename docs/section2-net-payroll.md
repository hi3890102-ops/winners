# 세후급여·가불·무급휴무

매장 인건비는 월 귀속 세후급여를 사용한다. 실제 확인액은 가불을 포함한 월 전체 세후급여다. 가불은 남은 지급액만 차감하고 월 인건비에서 다시 빼지 않는다. 실제 확인이 없으면 기존 공제율에 의한 참고 추정치로 표시한다. 보험료·급여 원천세 납부는 별도 지출 분류로 기록한다. 과거 거래는 자동 재분류하지 않는다.

무급휴무는 체크와 날짜로 등록한다. 월급제는 해당 월 일수로 나눈 참고 일급을 차감하며, 시급제는 확인된 근무시간으로 이미 계산되므로 추가 차감은 0원이다. 새 반차 등록은 제거하되 기존 기록은 보존한다. 실제 급여 확인 후 가불 외 조정이 바뀌면 재확인해야 한다. 2026-10-03 추가 결정: 입사일이 없는 월급제도 해당 월 1일부터 재직한 것으로 보고 등록 월급을 추정 계산한다. 이번 달은 오늘까지, 과거 달은 월 전체, 미래 달은 0원이다. 입력된 입·퇴사일은 일할 계산에 반영한다. 원본 입사일과 확정된 실제 세후급여는 변경하지 않는다.

권한: 사장님·매니저만 급여를 수정한다. 직원은 본인만 조회한다. 변경 이력은 서버에서 기록하고 직원 조회·클라이언트 조작을 차단한다. 만료 세션은 조회할 수 없다.

검증: `node --test security/*.test.mjs tests/*.test.mjs` 563개, 통과 554개, 기존 건너뜀 9개, 실패 0개. 운영 환경 빌드 통과. 신규 급여 계산 8개와 실제 Postgres RLS/트리거 3개 테스트 포함. 스테이징·운영에서 `security/net-payroll-live-rollback.sql` 합성 사용자 역할 검증 통과, 모든 검증 데이터는 롤백했다. 실제 휴대폰 화면 조작은 아직 검증하지 않았다.

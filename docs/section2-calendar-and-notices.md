# 매장 휴무일과 매니 본사 공지

매장 설정에서 요일별 정기휴무, 특별 휴무일, 휴무일 영업 예외를 저장한다. 직원의 무급휴무와 독립적이다. 설정한 휴무일은 어제 매출보고 누락 경고에서 제외한다. 매출보고를 삭제하거나 자동 생성하지 않는다.

사장님의 운영 → 공지와 더보기 → 알림 모아보기에 매니 본사 공지를 표시한다. 전체·현재 매장·소속 브랜드 공지만 표시한다. 대상 매장 구성원 읽기 권한을 추가하고 기존 실세션 제한을 유지했다. 등록한 본사 공지가 없으면 빈 상태로 표시한다.

검증: 전체 566개 테스트 중 557개 통과, 기존 9개 건너뜀, 실패 0개. 운영 빌드 통과. 스테이징 합성 사용자 역할 검증 통과, 데이터 롤백. 운영 스키마 적용 확인. 운영 합성 역할 검증 요청은 연결 도구의 Invalid or expired requestState 오류로 결과를 받지 못했으며 운영 역할 재검증은 미확인이다. 휴대폰 실사용 검증도 미확인이다.

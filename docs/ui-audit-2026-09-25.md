## 실제 사장님 계정 화면 점검

안전한 로그인 절차로 사장님 계정에 로그인한 뒤 운영 배포를 새로고침하여 확인했다. 계정 비밀번호를 코드나 기록에 저장하지 않았다.

- 로그인 유지, 홈 매장 필터 변경 및 해당 매장 카드 표시 확인.
- 매출: 지출 탭, 거래처 관리 열기/닫기, 기존 지출 수정 열기/취소, 월간 리포트 이동 확인. 하단의 불필요한 “매출보고로 이동” 버튼이 제거된 상태 확인.
- 직원: 근태·스케줄·직원관리·급여 메뉴 이동, 고정 근무 설정 열기/뒤로 확인.
- 운영: 체크리스트 지난 기록 열기, 예약 화면, 공지 작성 열기/취소 확인.
- 더보기: 매장 설정·알림 모아보기·AI 물어보기 이동 및 복귀 확인.
- 운영 HTML이 배포 빌드와 동일한 SHA-256임을 확인: `3f78b9db22b47c0e21ff30efdf41de65ff89c2753b2f98aca65103da708f3766`.
- 점검 중 지출·급여·공지·예약 등 업무 데이터를 저장하거나 삭제하지 않았다.

## 사용성 개선 후보

홈에서 선택한 매장은 홈 조회 필터에만 적용된다. 홈에서 특정 매장을 선택하고 매출 메뉴로 이동하면 기존 작업 매장이 표시되는 동작을 직접 확인했다. 이는 현재 코드와 기존 회귀 검사가 요구하는 설계이며 이번에 변경하지 않았다. 사용자가 선택한 매장이 계속 유지된다고 생각하면 혼동할 수 있어, 홈 필터라는 안내를 명확히 하거나 전역 매장 선택으로 통일할지 별도 검토가 필요하다.

## 남아 있는 검증 범위

사장님 주요 조회·탐색·취소 흐름은 로그인된 운영 브라우저에서 확인했다. 매니저·직원은 코드와 회귀 검사로 확인했으며 해당 역할의 실제 로그인 E2E는 수행하지 않았다. 이벤트 중복 재현 검사는 실제 소스 함수를 DOM 대역과 함께 실행한 검사다.

브라우저 너비는 1363px이며 앱의 좁은 중앙 레이아웃을 확인한 것으로, 실제 Android/iOS 터치 검증을 대신하지 않는다. 긴 매장명·큰 글꼴, 모바일 네이티브 선택 팝업과 화살표 터치, 사진 업로드, 위치·알림 권한, 파일 다운로드, 저장·삭제 완료 흐름은 남아 있다. 변경을 남기는 검사는 별도 테스트 계정/데이터로 진행할 것.

# 직원 공용 스케줄 — 2026-10-02

직원·매니저·사장님은 자신이 현재 연결된 매장의 모든 일일 근무를 등록·수정·삭제할 수 있다. 직원의 내 스케줄 화면에서 우리 매장 전체 스케줄 버튼으로 이동한다. 일반 직원에게 근태 확정·수기 출퇴근·고정 패턴 관리 권한은 추가하지 않는다.

기존 근무 수정은 직원 ID를 재배정하지 않고 근무일과 시작/종료 시간만 바꾼다. 삭제는 확인 후 서버가 실제 삭제한 행을 반환해야 반영한다. 저장 실패·0행·중복 클릭·매장/계정 전환 후 늦은 응답은 원래 자료를 훼손하지 않는다.

DB 변경은 활성 직원 membership + 실제 유효 세션 + 같은 매장 직원 조건을 모두 요구하는 shifts 정책과 서버 트리거 기반 변경 이력을 추가한다. 이력은 매장 관리자만 읽고 클라이언트는 추가·수정·삭제할 수 없다. 기존 이력 및 운영자료를 수정하지 않는다.

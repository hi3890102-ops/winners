# 프랜차이즈 월별 손익

월 선택, 가맹점 검색·8개씩 더 보기, 운영 활성도, 가입 수, 매장당 평균 매출·세후급여·지출·예상 순수익을 제공한다. 평균은 매출보고가 있는 유효 매장으로 계산하며 집계 매장 수와 전체 수를 표시한다. 순수익 미확정은 0원으로 대체하지 않는다. 브랜드별 인건비·식자재 상한, 순이익 하한을 설정한다. 순이익 기준은 초기 미설정이다. 미분류 지출이 있으면 식자재 판정을 보류한다.

공통 서버 계산: 실매출 = 총매출 - 할인 - 반품. 예상 순수익 = 실매출 - 월 귀속 세후급여(가불 포함) - 지출 - 고정비. 비율은 할인 전 총매출 기준이다. 실제 은행잔액이 아니다. 영업일수는 실제 매출보고 날짜 수이고 휴무일 달력으로 보고 누락 일수를 구분한다.

프랜차이즈 RPC는 자기 브랜드만 조회하며 직원·사장 이름·연락처·계좌·직원 식별자는 반환하지 않는다. 원시 직원·매장·매출·근태·스케줄·급여조정은 본인 매장 구성원 또는 플랫폼 역할만 접근하도록 제한한다. 프랜차이즈는 소속 매장 디렉토리와 익명 금융 API를 사용한다. 실제 세션이 필요하다.

검증: public repo 568개 중 559개 통과·기존 9개 건너뜀·실패 0개. 관리자 UI 신규 5개 통과. 운영 빌드 통과. 스테이징 실제 역할 합성 검증 통과·롤백. 급여 추정 직원이 포함된 SQL 변수명 충돌을 수정하고 회귀 시나리오를 추가했다. 실제 휴대폰·프랜차이즈 로그인 UI 조작은 아직 미검증이다.

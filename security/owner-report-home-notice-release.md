# 보고서 마무리 홈 안내

푸시 재연결 없이도 지정된 사장님이 보고서 비용 확인을 시작할 수 있도록 홈 상단에 안내와 해당 월 비용 확인 버튼을 추가한다.

- 수신 대상은 서버의 `owner_report_home_notices`에 계정·매장·월 조합으로 별도 등록한다. 앱 코드에 운영 계정이나 매장 식별자를 넣지 않는다.
- 본인의 살아 있는 로그인 세션과 해당 매장 사장님 권한이 모두 있어야 조회할 수 있다. 다른 계정, 직원, 권한이 해지된 사장님은 볼 수 없다. 브라우저에는 조회 권한만 부여한다.
- 매장의 해당 월 비용 확인을 완료하면 서버 조회에서 안내가 제외된다. 다른 휴대폰도 홈 진입 또는 앱 복귀 시 최신 상태를 읽는다. 비용 내용이 바뀌어 확인이 다시 필요해지면 기존 비용 확인 무효화 규칙에 따라 안내가 다시 나타난다.
- 버튼은 현재 선택된 월에 관계없이 안내에 지정된 매장·월의 기존 비용 확인 화면을 연다. 매출·지출·급여·마감본을 자동으로 수정하지 않는다.
- 전체 매장 홈은 같은 월의 안내를 한 카드에 모아 미완료 매장 수와 매장별 버튼을 표시한다. 매장 선택 시 해당 매장만 표시하며 한 매장의 완료가 다른 매장 안내를 지우지 않는다.
- 이번 안내는 홈 전용이다. 푸시 발송 함수·예약 작업을 호출하지 않는다.

검증: 대상 계정 제한, 같은 매장의 다른 사장님 차단, 계정 전환 중 늦은 응답 차단, 지정된 매장·월 이동, 확인 완료 시 다른 기기에서 숨김, 권한 해지·로그인 만료 차단을 테스트한다. 실제 DB 검증은 합성 계정으로 실행 후 전체 롤백한다.

배포: 마이그레이션을 스테이징에서 검증한 뒤 운영에 적용하고 앱을 배포한다. 대상 행은 별도 승인된 단일 계정·매장·월에만 삽입한다. 복구는 해당 안내 행 제거 또는 직전 앱 배포 복원으로 가능하며 기존 장부는 건드리지 않는다.
